# Đa ngôn ngữ (i18n) & Dark mode

## Ngôn ngữ
`src/i18n/languages.js`: en (gốc + fallback) và vi. Thêm ngôn ngữ: dòng mới trong languages.js + thư mục `locales/<code>/` (đủ namespace) + loader trong `I18nContext.js`. Lựa chọn lưu `localStorage["tripnova.lang"]`, lần đầu lấy theo ngôn ngữ trình duyệt.

- Từ điển: `src/i18n/locales/<lang>/<namespace>.json`, khai báo trong `locales/<lang>/index.js` (mọi ngôn ngữ cùng danh sách namespace).
- Tiếng Anh đóng gói sẵn, ngôn ngữ khác tải lazy (chunk `locale-xx`). Khoá thiếu → tự lấy tiếng Anh.
- Kiểm tra: `npm run i18n:check` (khớp khoá giữa các ngôn ngữ, khoá dùng trong code có tồn tại, biến `{{x}}` khớp).

## Cách dùng trong component
```js
import { useT } from "../../i18n/I18nContext";       // hoặc useI18n() nếu cần lang/locale/changeLanguage

function HotelCard({ hotel }) {
    const t = useT();
    return (
        <>
            <h3>{hotel.name}</h3>                                   {/* dữ liệu từ API: KHÔNG dịch */}
            <p>{t("hotels.card.roomsLeft", { count: hotel.remainingRooms })}</p>
            <button aria-label={t("common.actions.close")}>…</button>
        </>
    );
}
```
- Khoá: `<namespace>.<nhóm>.<tên>` camelCase, VD `hotels.filters.starRating`. Namespace = tên file JSON.
- Biến: `{{name}}` → `t("x.hello", { name })`.
- Số nhiều: truyền `count`; tiếng Anh có `key_one` / `key_other`, tiếng Việt chỉ cần `key_other` (theo Intl.PluralRules).
- `defaultValue`: `t(\`common.status.${s}\`, { defaultValue: s })` cho khoá động.
- Mảng / object hằng khai báo ngoài component (options, label map): chuyển vào trong component, hoặc lưu `labelKey` rồi `t(item.labelKey)` lúc render.
- Ngày giờ / tiền: dùng `formatDate`, `formatDateTime`, `formatMoney` (`utils/formatters.js`, tự theo ngôn ngữ đang chọn). Cần Intl riêng thì dùng `getCurrentLocale()` (`i18n/currentLocale.js`), không viết cứng `"en-GB"`/`"en-US"`.
- Dùng lại `common.*` (actions, state, status, units, fields, paymentMethods) và `nav.*` khi đúng nghĩa.

KHÔNG dịch: dữ liệu từ API (tên khách sạn, mô tả…), thương hiệu "Tripnova"/"TripNova", tên icon trong `<span className="material-symbols-outlined">`, giá trị enum gửi lên API, route, class CSS, comment, console. Lỗi server (`err.message`) hiển thị nguyên văn.

Trang admin / manager cũng song ngữ: namespace `admin` (layout, components/admin, pages/admin; trạng thái động `admin.status.*`, thống kê `admin.stats.*`) và `manager`.
- Cấu hình biểu đồ `components/admin/adminStatsConfig.js` chỉ chứa khoá (`titleKey`/`labelKey`/`noteKey`), không chứa chữ. Nhãn breakdown BE trả về: mã cố định → `admin.stats.values.<mã>`, khoảng "2 nights" → `admin.stats.bucket.<đơn vị>` (`localizeBreakdownLabel` trong AdminStatsPanel).
- Số nhiều: luôn `t("x.count", { count })`, KHÔNG tự chọn `_one`/`_other` trong code (tiếng Việt chỉ có `_other`).
- Không đặt tên biến lặp là `t` trong component đã có `const t = useT()` (VD `TABS.map((t) => t(t.labelKey))` → lỗi "t is not a function").

## Dark mode
`context/ThemeContext.js` (light | dark | system, `localStorage["tripnova.theme"]`), class `dark` trên `<html>` (script trong `public/index.html` đặt trước khi React chạy). Nút: `components/common/ThemeToggle`, chọn ngôn ngữ: `components/common/LanguageSwitcher`.

Màu Tailwind (token thiết kế + bảng màu mặc định) là biến CSS — `theme.palette.js`: đổi theme không cần sửa trang. Quy tắc khi viết giao diện mới:
- Ưu tiên token: `bg-surface`, `bg-surface-container-low`, `bg-white` (thẻ), `text-on-surface`, `text-on-surface-variant`, `text-primary`, `border-outline-variant`.
- Nền nhạt 50–300 và chữ đậm 600–900 tự đảo trong dark mode; nền đậm `bg-*-500..900` / `bg-primary` giữ đậm để chữ trắng trên nút vẫn đọc được.
- Tránh màu hex viết cứng (`text-[#003580]`, `style={{ color: "#..." }}`); nếu bắt buộc thì thêm override `html.dark …` trong `index.css`.
- Chữ trên nền luôn tối (ảnh, footer navy): dùng `text-white/70…` thay vì `text-gray-300` (xám bị đảo trong dark mode).
